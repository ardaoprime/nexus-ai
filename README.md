# NEXUS AI

A React + Vite starter for a beginner-friendly business-building workspace.

## Run locally

```bash
npm install
npm run dev
```

## Current status

This first commit contains the responsive dashboard and navigation prototype. The dashboard currently uses demo/empty states: it does not yet perform live market research, connect an AI provider, store financial records, or publish generated websites.

## Next milestones

1. Connect a secure backend and AI provider without exposing API keys in the browser.
2. Add a guided business idea and market research workflow with source links.
3. Add project persistence and real income/expense tracking.
4. Build a website creation workflow and preview.
5. Add marketing planning and automation integrations.

Start with free tools where practical; external services may have usage limits or paid tiers.
